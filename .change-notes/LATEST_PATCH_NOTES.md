# Spotify+ 0.3.6

- Spotify+ now stands down completely when an integrated Lyssna Lyrics build is running. Its menu, tools and feature handlers stay unloaded, and it resumes with Spicy Lyrics or a build without Enhancements.
- The installed launcher now loads the latest published Spotify+ release when Spotify starts. Update to 0.3.6 once to receive the launcher; future updates only need a Spotify reload.
- If a later release download fails, the launcher can use its cached runtime. Downloaded builds are checked against GitHub's published checksum when available.
